## About

This repository preserves findings from five Final Fantasy XIV 1.23b Windows
executables: objects, dispatch, resource formats, state, and subsystem links.

The tracked tree contains research notes, machine readable catalogs, headers
that preserve evidence, and reproducible analysis tools. It is a research
catalog, not a buildable client source tree.
